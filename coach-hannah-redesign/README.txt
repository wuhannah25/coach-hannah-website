Coach Hannah 網站改版｜手機／電腦響應式

使用方式：
1. 解壓縮 ZIP，會看到 index.html 與 logo.png。
2. 先用瀏覽器開啟 index.html 預覽。
3. 確認內容後，登入 Netlify，進入 hannah-profile 專案的 Deploys，將整個網站資料夾拖曳部署（會更新既有網址）。
4. 更新資訊：用文字編輯器打開 index.html，搜尋想修改的文字或價格，儲存後重新上傳資料夾。

提醒：這個版本是獨立新設計，不是舊網站原始碼的修改。部署前請先備份舊網站原始資料夾。
